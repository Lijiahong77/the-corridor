### 已知踩坑
- **角色一致性漂移**：完全独立生成的多张图，人物长相会变（定妆短发 → 镜01 长发）。
  对策：出角色出镜镜头时，先把定妆图 `upload_image` 拿 `image_id`，再走带参考图的生成路径。
- TapNow 出图工具的 `create_hero_image` **没有参考图参数**；要参考注入得走 `create_product_shots` / `create_deck_visuals`。
- **底图 onload 串台**（v0.1 就存在）：`<img>` 的 `onload` 挂了不摘 → 新图 load 时旧回调再触发，
  把**上一节点重画一遍**。修复要点：`bg.onload = null` 用完即摘 + 单调 `seq` 令牌弃用旧回调。
  同类"闭包挂在 DOM 上"的 bug 读代码看不出来，**必须真跑**。
- **首帧图已处于某状态时，别让它演「进入该状态」的动作**：首帧是「睁眼」→ 提示词写「缓缓睁开眼睛」
  必失败（模型无法倒回去演），只会得到极微小的眼神游移；改用**整体性运镜**（推/移）承载变化。
  开场镜头尤其适用 —— **变化可见性 > 动作精细度**，否则固定时长会让观众以为「视频卡住了」

## 互动原型（网页）
- 构建：`回廊\_build\template.html`（模板，含占位符）+ `build.py` → **`回廊\回廊_互动原型.html`**（自包含单页，图片与视频全 base64 内嵌，双击即玩）
- 加素材 = 在 `build.py` 的 `repl` 里加一行占位符映射，再跑 `build.py`
- **给节点挂视频只需改三处**（引擎不用动）：节点数据加 `video:"vN"`、`VID` 表加 `vN:"__VID_MN__"`、`build.py` 加映射
- **视频插哪里的铁律**（按"变化是否即剧情信息 + 会不会泄露选项结果"判，三类）：
  1. 只有当"变化本身就是剧情信息"才做视频，**静态图够用的就别做**（静物硬加运镜会假）
  2. 展现**当下正在发生的事**（v1 醒来 / v2 敲门）→ ✅ 可放**节点进入画面**
  3. 展现**选择之后的后果**（v4 人影吞掉你）→ ❌ 必须放**选择之后当过场**，否则悬念泄光
  4. 展现**结局本身** → 用 `endvid` 字段 = **叙事型结局视频**（v6 真结局天台）：
     播一次、**不循环**、走完**停在末帧** → 结局卡压上去。三种视频不能混：
       `video`  = 过场：播一次 → 撤掉 → 静态图 → 后续内容；**必须给「点击跳过」**
       `endvid` = 叙事型结局：播一次 → **停在末帧不撤** → 结局卡压上去；**不给跳过**（李要求：必须看完才出结局）
       `bgvid`  = 常驻循环背景（**当前无节点使用，留备用**）：loop=true、不撤、不给跳过
     `clearVideo()` 会把 `vid.loop` 复位为 false，所以只有 `bgvid` 才循环
- 现有视频：`v1` 镜01 醒来（start）· `v2` 镜02 敲门（n1）· `v4` 镜04 电梯（循环结局过场）·
  `v6` 镜06 真结局 天台（**李自备素材** 1280x720/24fps/15s：走出楼道 → 俯瞰整座城市）
- **循环视频必须首尾接得上**（备用知识）：单向运动直接循环会明显跳 →
  ffmpeg `split/reverse/concat` 做**正放+倒放「乒乓」**，首尾天然衔接；幅度靠 `setpts` 慢放收
  ⚠️ 模型对"极缓慢"的响应是**二值的**：要么大动、要么完全不动
  另有一招在 `_build\make_pan_video.py`：**超宽图 + crop 余弦平移**（完全可控，4 秒出片）
- 播放约定：进节点自动播一次 → **非结局节点保留视频末帧**直接出旁白（无跳变）→ 结局节点沉黑后切底图
- ℹ️ **体积**：当前 **20.54MB**（4 视频 + 6 图 + 2 音频）。李明确「不用控制大小，我在浏览器里预览」
  → 继续 base64 内联；但已到"打开明显变慢"的量级（20MB data URI 解码约 3 秒），再加镜头前先算账
- **真结局「天台」必须保持有画面**（李明确要求），v1.0 现状：
  - 素材 `画面\镜06_真结局_天台.mp4`（李自备，人物不入画的第一人称视角）
  - ⚠️ `#app.endlight` 现在是**暗底**（深夜城市）→ 整套配色反过来：
    **浅色字 + 暗纱蒙版 + 黑色光晕**（旧的"白纱 + 深色字"作废）。
    规律记住：**底亮则字深、底暗则字浅**，别写死一种
  - ⚠️ 交棒时机：`MUSIC.toEnding()` 在**视频开始**那一刻调（走出铁门 = 换世界），
    不放在 `showEnding()` —— 已加幂等守卫，两处调用只生效一次
  - **不可跳过机制 `vidLock`**（v1.1，李要求「视频不可跳过，一直到播完出结局文字才能重玩」）：
    `playVideo(key, done, lockSkip)` 第三参为 true → 不显示「点击跳过」+ `skipVideo()` 直接 return。
    三个跳过入口（点提示 / 点画面 / 键盘）都汇到 `skipVideo()`，所以**只需在一处设卡**
  - ⚠️ **`pointer-events:none` 管不住子元素**：`.endcard` 设了 none，但 `#end-restart` 自己写了 auto
    → **结局卡还没浮现时，那个看不见的按钮照样点得到**（点中立刻 reload），
    这就是"视频没看完也能重来"的真凶。只能靠 **`disabled` 属性**拦
    （`pointer-events` 拦不住合成事件与 `el.click()`，`disabled` 才挡真实鼠标）
    → 约定：**隐藏的可交互元素一律用 `disabled` 锁，别只依赖 `pointer-events` / `opacity`**
  - 验证用 `_build\_probe_noskip.mjs`（12 项）：⚠️ **必须用 CDP `Input.dispatchMouseEvent` 发真实输入**，
    `dispatchEvent(new MouseEvent(...))` 会绕过 `disabled`，测出来是假的
- ⚠️ **配图必须与文案咬合**：给新死亡节点/分支配图前**先读文案**，别图省事复用。
  实例：d1 文案说「门外的走廊是空的」，曾复用 m2（门外有双脚在逼近）→ 图文互相拆台；
  已补专图 `m5`（镜05 猫眼空走廊：圆形猫眼视野 + 门外空无一人）
- **声音**：两条音轨 + 4 个音效（敲门 / 灯灭灯亮 / 电梯 / 死亡）
  - 音轨由 `makeTrack(id, src, {volume, loop})` 工厂产出：`BGM`（`#bgm`，loop，0.50）+ `ENDMUS`（`#endmusic`，不循环，0.62）
  - 点「进入」起播铺底乐（3.5s 淡入）· **真结局「天台」交棒**：`MUSIC.toEnding()` = 铺底乐 3.5s 淡出 → 空 1.8s → 结尾曲 2.6s 淡入
    （常量 `END_HANDOFF_MS / END_GAP_MS / END_FADE_IN_MS`）· 循环结局不切 · 右上角开关同时管两条音轨与音效
  - ⚠️ 交棒要放在 `showEnding()` 里调，**别放 `SND.ending()`** —— `SND` 有 `if(!ready) return`（WebAudio 未启动就早退），
    而音轨只碰 `<audio>` 元素，不该被 WebAudio 状态拦住
  - ⚠️ `<audio>` 用**属性**声明 src 时，`loadedmetadata` 可能在末尾脚本挂监听**之前**就触发
    → 必须"挂监听 + 立刻主动 `syncMeta()` 补读一次"，只等事件会漏
- 验证：`回廊\_build\_verify.mjs`（CDP 直驱 headless Edge，**无需装 Playwright**）；天台段 v1.0 重写为「播一次 / 停末帧 / 交棒时机」三组断言
  - 💡 **调视觉时别跑完整验证**（2 分 49 秒太慢）→ 用 `_build\_probe_ending.mjs`：
    加载页 → 点进入 → 直接 `goto('end_true')` → 截图，**约 15 秒出图**，
    一轮"改 CSS → 重建 → 看效果"压到 30 秒。`goto` / `NODES` 在顶层 `<script>`（非 module），CDP 能直接调
  - ⚠️ **失败先分清是产品 bug 还是断言自己写错**：本轮"视频时长"报 FAIL，
    实为我按 5 秒写、成品是慢放乒乓后的 22.3 秒 —— 改测试，不是改产品
  - ⚠️ **CDP 端口会卡 TIME_WAIT** → 两个验证脚本都支持 `CDP_PORT=xxxx` 环境变量覆盖，profile 目录带端口号
  - ⚠️ 缩短循环的坑：断言必须晚于"平滑淡出"走完（天台 BGM 淡出 3.5s、结尾曲 1.8+2.6s）
  - ⚠️ 加断言时**必须连着加它的前置动作** —— 曾只加断言忘加点 E1 的 click，报了假 FAIL
  - ⚠️ 断言判据要用 `.choice:not(.disabled)`（旧按钮只加 disabled、不清空）
  - 💡 script 顶层 `const`（如 `IMG` / `NODES`）在 CDP `Runtime.evaluate` 里可直接访问，
